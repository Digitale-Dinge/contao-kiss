### Updating documentation

The documentation is built using mkdocs_material https://squidfunk.github.io/mkdocs-material/

#### Installation

**Install python if it does not exist on your system yet**

```shell
brew install python
```

**Install mkdocs and the plugins**

```shell
pip3 install mkdocs-material
pip3 instsall mkdocs-glightbox
```

#### Serving the documentation

```shell
mkdocs serve
```
